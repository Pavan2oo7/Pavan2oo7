# Pavan Patel — Developer Portfolio

A modern, responsive developer portfolio built with **HTML + CSS + a tiny bit of JavaScript** for scroll-reveal and smooth navigation.

## ✨ Features

- Dark developer-focused visual design
- Responsive layout for desktop, tablet and mobile
- Animated orbit / terminal hero section
- Skill cards and project cards
- Scroll reveal animations
- No frameworks or build tools required
- Ready for GitHub Pages

## 🚀 Run locally

Open `index.html` directly in your browser, or use VS Code Live Server.

## 🌐 Deploy on GitHub Pages

1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html` and `style.css`.
3. Replace placeholders such as `YOUR_USERNAME`, `YOUR_LINKEDIN`, and `YOUR_EMAIL`.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/root`.
6. Save. GitHub will provide your Pages URL.

## 🔧 Customize

The easiest visual changes are in the `:root` section at the top of `style.css`.

Project links currently use `#`; replace those with your real repository/demo URLs.
